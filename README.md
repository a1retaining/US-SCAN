# TradingMint PRO

GitHub-ready automated trading scanner and decision dashboard.

## Includes

- Premium TradingMint PRO frontend
- Automated scanner loop
- Market regime engine
- Relative strength and trend scoring
- Risk/reward filter
- Position sizing engine
- Automated backtesting
- Expectancy tracking
- Paper trading engine
- 60-second trade popup
- Persistent reports in `data/reports`
- Test suite

## Run locally

```bash
npm install
npm test
npm start
```

Open:

```txt
http://localhost:10000
```

## Upload to GitHub

```bash
git init
git add .
git commit -m "Initial TradingMint PRO build"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/tradingmint-pro.git
git push -u origin main
```

## Deploy on Render

```txt
Build Command: npm install
Start Command: npm start
```

This project is a scanner, research tool and paper-trading system. It is not financial advice.
